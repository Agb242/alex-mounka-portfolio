# Alex Mounka — Portfolio

Site portfolio d'Alex Guy Blanchard Mounka (Architecte Infra Résiliente & Scalable · FinOps · DevSecOps · IA · Conseil).

Site statique, une seule page `index.html`, sans dépendance de build. Déployé sur Vercel.

## Développement local

Aucune étape de build : ouvrir `index.html` directement, ou servir le dossier avec n'importe quel serveur statique, par exemple :

```bash
python -m http.server 8080
```

## Déploiement

Déploiement automatique sur Vercel à chaque push sur `main`.
